Quick setup

Complete these two steps first. The full instructions follow below.

🟣

1. Create a Twitch app

Register an app in Twitch Developer Console, use the settings below, then copy its Client ID into Twitch Music Player.

1

Install the player

Choose the installer or a portable archive, depending on what the release provides.

Installer

  1. Download the latest setup file from GitHub Releases.
  2. Run the installer and follow the prompts. The standard install is per-user and does not require administrator access.
  3. Launch Twitch Music Player from the Start menu or desktop shortcut.

Portable ZIP, if available

  1. Extract the archive to a permanent folder, for example D:\TwitchMusicPlayer.
  2. Run TwitchMusicPlayer.exe from that folder. Do not move the folder while the app is running.
If Windows SmartScreen shows a warning, check that you downloaded the file from the official release page and verify its SHA-256 shown on GitHub before continuing.
2

Connect Twitch and authorize the player

The Client ID identifies the registered app. Twitch authorization connects your account.

Register the developer application

  1. Go to Twitch Developer Console → Applications and sign in to the account that manages your channel.
  2. Choose Register Your Application. Give it a name such as Twitch Music Player.
  3. Set OAuth Redirect URL to http://localhost/.
  4. Set category to Broadcaster Suite and client type to Public, then register.
  5. Open the app and copy the Client ID. In Twitch Music Player, open Twitch settings, paste the ID, and save.
Do not generate, paste, or publish a Client Secret for this setup. The application uses the public client flow and only needs the Client ID.

Authorize your Twitch account

  1. In the player, open Twitch settings and choose Connect / Authorize with Twitch.
  2. A Twitch page opens. Sign in to the correct account, review the requested permissions, and choose Authorize.
  3. Return to the player and wait for the Twitch status to show connected.
If the browser shows a localhost page after authorization, return to the player; it completes the local sign-in flow. Never send anyone your authorization code or access token.
3

Set up Channel Points song requests

Create a reward that the player can listen for and configure the matching reward in the app.

There are two ways to create the reward. Use whichever is available in your Twitch Music Player version.

Option A — create a reward from the player

  1. Open the Twitch section in the player and go to Rewards.
  2. Select Create song request reward.
  3. Set a reward name, for example Request a song, and its point cost. Choose a value that fits your channel.
  4. Enable viewer text input. Set the prompt to Paste a YouTube link or enter a song title.
  5. Create the reward, refresh the list, select it, and start listening for requests.

Option B — create a reward on Twitch

  1. Open Twitch Creator Dashboard → Viewer Rewards → Channel Points → manage rewards.
  2. Choose Add a Custom Reward. Enter a name and point cost.
  3. Enable viewer text input and add a prompt asking for a YouTube link or song name. Save the reward.
  4. In the player, refresh the rewards list and select the reward to monitor.
If the player asks for a Reward ID, select the reward from the refreshed list instead of typing its display name. If it does not appear, check that the player is authorized to manage rewards and refresh again.
4

Connect Donatik

Use the private moderator link from the music widget. This is not the public donation page or the OBS Browser Source URL.

  1. Sign in to your Donatik account.
  2. Open the settings for your music request widget, commonly named Music requests or Music orders.
  3. Find the moderator link. It may be labelled Moderator link or Moderator URL.
  4. Copy the entire private link.
  5. In Twitch Music Player, open Donatik settings. Paste the moderator link into the Donatik link field and save.
  6. Choose Connect or Reconnect and wait for the status to confirm the connection.
Keep the moderator link secret. Anyone with it may be able to manage music requests. If it is exposed, regenerate or replace it in Donatik and update the player.

About request priority

Donatik requests may be given priority over regular requests. When the current track ends, the player continues with the next item in the queue according to its priority rules. Exact menu labels can differ between Donatik widget versions.

5

Test the connections

Use a test request before relying on the setup during a stream.

  • Twitch shows as connected in the player.
  • The Channel Points reward exists, is selected in the player, and request listening is active.
  • Donatik shows as connected.
  • The queue and status indicators update when a request arrives.

Test Twitch

Use a second Twitch account to redeem the reward with a public YouTube URL or a song title. Confirm the request appears in the queue and playback starts as expected.

Test Donatik

Submit a test music request through your Donatik widget. Confirm it is imported into the queue and that the widget reflects the request's progress or removal as expected.

Test requests can affect your live widget and queue. Remove test entries when you are done.
6

Add the now-playing overlay to OBS

The player serves the overlay locally while it is running.

  1. Open OBS Overlay settings in the player and make sure the local HTTP server is enabled.
  2. Copy the overlay URL shown by the player. Do not guess or type the address: its port may depend on your settings.
  3. In OBS, select the scene and choose + in Sources → Browser.
  4. Name the source, paste the copied URL, and set width and height to match your stream layout.
  5. Confirm that the player is running and preview the scene. Adjust overlay options in the player if available.
Keep Twitch Music Player running while using the overlay. If it stops loading, check that the local server is enabled and copy its current URL again.
7

Troubleshooting

Check these common causes before reconnecting or recreating settings.

The Client ID is rejected

Confirm you copied the Client ID, not the Client Secret or another value. Check that the app's redirect URL is exactly http://localhost/, and that the app uses the Public client type.

Twitch connects, but the reward is missing

Make sure the correct Twitch account is authorized, the reward is active, and you have refreshed the list in the player. Reauthorize if the app's permissions changed.

Donatik will not connect

Use the private moderator link for the music widget. Check that the complete link was copied without extra spaces and that it is still valid in Donatik.

The OBS overlay shows a blank page

Make sure the player is running and its local overlay server is enabled. Copy the URL from the current player settings and update the Browser Source.

Requests do not play

Check that the queue is not paused, the selected reward is the one viewers are redeeming, and the media link is available. Try a public YouTube video.

8

Security, settings, and backups

Protect account access and keep a backup of your local configuration.

  • The app stores settings locally in the current Windows user profile. Twitch credentials are managed through Windows Credential Manager when available.
  • Logs are stored in the app's logs folder and may include diagnostic details. Review them before sharing.
  • Back up the app's settings/database and logs folder before moving to another computer. The exact location can vary by install type and app version.
  • Never publish a Twitch Client Secret, OAuth token, Donatik moderator link, or unredacted logs.
  • For public documentation, include only general setup steps and examples with no real credentials.
You are ready to use the player once Twitch and Donatik show connected, a test request reaches the queue, and the OBS overlay displays correctly.
